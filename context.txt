2️⃣ Core Domain Rules (Must Be Enforced)
Consent Model

Consent is the source-of-truth entity.

Rules:

Consent has a lifecycle (enum-driven)

Status transitions must be valid and controlled

No direct status mutation without event recording

All transitions create a ConsentEvent row

All write operations create an AuditLog entry

Consent state must never be derived from events — it must be authoritative and consistent.

Event log must be append-only.

ConsentEvent Model

Represents state transitions.

Rules:

Must reference a consent

Must record old status and new status

Must store timestamp (UTC)

Must never be deleted

Must reflect a valid state transition

AuditLog Model

Compliance-critical.

Rules:

Every write action must create an audit log

Must record actor (system/admin/external)

Must record action type

Must record timestamp

Must be immutable

Missing audit log = compliance failure.

3️⃣ Migration Discipline (Critical Risk Area)
